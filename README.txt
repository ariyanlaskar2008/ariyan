RUNNER BY ARIYAN
================

HOW TO PLAY
1. Extract the ZIP file.
2. Open the runner_by_ariyan folder.
3. Double-click index.html (Chrome or Edge recommended).
4. Upload a selfie, then press START RUN.

CONTROLS
- Left / Right arrows or A / D: change lanes
- Up arrow / W / Space: jump
- Down arrow / S: slide
- P or Esc: pause
- On mobile: swipe left/right/up/down

AUDIO
- assets/audio-1-start.mp3 plays when a run starts.
- assets/audio-3-gameover.mp3 plays when the run ends.

FACE PRIVACY
Your selected photo is drawn locally in your browser and is not uploaded to a server.
Best score is stored locally in your browser.

HOSTING
Upload index.html and the assets folder together to Netlify, GitHub Pages, or another static host.
Do not upload only index.html; the audio files are in assets/.
This is a lightweight 2.5D browser game, not a full 3D Subway Surfers clone.
